# Học phần: Nhập môn Công nghệ số và Ứng dụng Trí tuệ nhân tạo (UET-VNU)

Kho lưu trữ này được xây dựng nhằm mục đích quản lý mã nguồn, lưu trữ tài liệu bài tập lớn và theo dõi tiến độ học tập các kỹ năng lập trình cốt lõi của cá nhân.

## 📌 Nội dung kho lưu trữ
* **HomeWork/**: Chứa toàn bộ các bài tập lập trình cơ bản (xử lý chuỗi, cấu trúc rẽ nhánh, thuật toán logic nâng cao).
* **Project_Resources/**: Tài liệu phân tích và kịch bản dự án số ứng dụng AI.

## 🛠 Công nghệ & Công cụ áp dụng
* Ngôn ngữ lập trình: Python
* Quản lý phiên bản: Git / GitHub
* Môi trường phát triển: VS Code / Jupyter Notebook
